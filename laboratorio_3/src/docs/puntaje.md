#	Criterio
CA-RF04-01	Dado que una solicitud ha sido recibida, cuando el sistema evalúa la solicitud contra los criterios de admisión configurados, entonces asigna un puntaje numérico de 0 a 100 basado en el porcentaje de criterios cumplidos.
CA-RF04-02	Dado que una solicitud cumple con todos los criterios de admisión, cuando el sistema calcula el puntaje, entonces asigna un puntaje de 100.
CA-RF04-03	Dado que una solicitud no cumple con ningún criterio, cuando el sistema calcula el puntaje, entonces asigna un puntaje de 0.
