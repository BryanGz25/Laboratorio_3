9. Criterios de aceptación (Dado/Cuando/Entonces)
RF-01: Registrar zona franca con criterios mínimos
#	Criterio
CA-RF01-01	Dado que soy un administrador autenticado, cuando ingreso los datos de una nueva zona franca (nombre, inversión mínima, empleos mínimos, sectores permitidos) y hago clic en "Guardar", entonces el sistema registra la zona franca y la muestra en la lista de zonas francas.
CA-RF01-02	Dado que estoy registrando una zona franca, cuando dejo un campo obligatorio vacío (ej: inversión mínima) y hago clic en "Guardar", entonces el sistema muestra un mensaje de error indicando el campo faltante y no guarda la zona franca.
